# GTXN Research Explorer

Interactive settlement & payments platform IA research — 14 platforms covering positioning, navigation, operational workflows, and information architecture.

## Usage

Open `index.html` in a browser. No build step required — fully self-contained.

## Platforms covered

Noah, BVNK, dLocal, Bridge, CrissCross, Lumepay, Thunes, Conduit, Rapyd, Nium, Airwallex, Fincra, Rafiki, Adyen
